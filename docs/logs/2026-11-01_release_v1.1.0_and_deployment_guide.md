## 2. Chi Tiết Các Bước Thực Hiện (Execution Steps)

### Bước 1: Nâng cấp script phát hành `deploy.ps1`
- Cập nhật kịch bản [`.agents/skills/deploy-app/scripts/deploy.ps1`](file:///d:/PROJECT/github.com/mdm-parental-control/.agents/skills/deploy-app/scripts/deploy.ps1):
  - Hỗ trợ biên dịch trực tiếp Flutter cho `admin-node` (`flutter build apk --debug`).
  - Hỗ trợ biên dịch Android Native cho `target-node` (`.\gradlew.bat assembleDebug`).
  - Tự động lưu trữ tệp APK vào thư mục `release/`.
  - Tự động tạo và đẩy Git Tag `v1.1.0` lên GitHub remote.

### Bước 2: Thực thi phát hành bản Release v1.1.0
- Kích hoạt lệnh:
  ```powershell
  powershell -ExecutionPolicy Bypass -File .agents/skills/deploy-app/scripts/deploy.ps1 -Target all -Version "1.1.0" -Notes "Bản phát hành chính thức v1.1.0: Tích hợp Supabase BaaS, Firebase Cloud Messaging, thương hiệu VFam Child & VFam Admin"
  ```
- **Kết quả đóng gói**:
  - `target-node`: Đóng gói thành công `vfam-child-1.1.0.apk` (10.0 MB).
  - `admin-node`: Đóng gói thành công `vfam-admin-1.1.0.apk` (195 MB).
  - Git Tag: `v1.1.0` được tạo và push thành công lên `origin`.

### Bước 3: Soạn thảo cẩm nang triển khai thực tế
- Xây dựng tài liệu chi tiết tại [`docs/HUONG_DAN_TRIEN_KHAI_THUC_TE.md`](file:///d:/PROJECT/github.com/mdm-parental-control/docs/HUONG_DAN_TRIEN_KHAI_THUC_TE.md) bao gồm 8 phần:
  1. Chuẩn bị tệp cài đặt (Release Artifacts).
  2. Chuẩn bị hạ tầng Backend (Supabase SQL & Firebase Secrets).
  3. Quy trình kích hoạt máy con qua ADB (`set-device-owner`) và Zero-Touch QR Code.
  4. Cài đặt app phụ huynh.
  5. Quy trình ghép nối OTP giữa 2 máy.
  6. Thử nghiệm các tính năng cốt lõi (Khóa khẩn cấp, cộng thêm giờ, Doze Mode).
  7. Bảng lệnh ADB và xử lý lỗi thường gặp.
  8. Tổng kết tiêu chuẩn Zero-Bypass.
