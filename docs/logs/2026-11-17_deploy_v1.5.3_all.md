## 1. Mục Tiêu Bản Phát Hành v1.5.3
- **Child DO Agent (`target-node`)**:
  - Mã phiên bản: `versionName = "1.5.3"`, `versionCode = 14`.
  - Cải tiến: Thiết lập `PackageInstaller.SessionParams` chuẩn cho Android 12+ (`USER_ACTION_NOT_REQUIRED`, `INSTALL_REASON_POLICY`), đổi tên stream ghi APK sang `base.apk`.
  - Bổ sung xử lý `STATUS_PENDING_USER_ACTION` trong `SilentInstallReceiver`.
  - Bổ sung fallback tự động mở màn hình Intent tiêu chuẩn nếu silent install thất bại.
- **Parent Admin Android (`admin-node`)**:
  - Mã phiên bản: `version: 1.5.3+12`.
  - Đồng bộ Icon mới, xử lý kiểm tra phiên bản chuẩn xác.
- **Parent Admin iOS Enterprise (`admin-node`)**:
  - Mã phiên bản: `version: 1.5.3+12`.
  - Ký số In-House VNPT Enterprise (`com.dhtthni.quanlytaptrung`).
  - Sửa lỗi crash khởi chạy do FlutterViewController.

## 2. Quy Trình Triển Khai
1. Build Target Node (`gradle assembleDebug`) -> Xuất `vfam-child-android-1.5.3.apk`.
2. Build Admin Node Android (`flutter build apk --release`) -> Xuất `vfam-admin-android-1.5.3.apk`.
3. Build & Ký số Admin Node iOS Enterprise qua máy Mac M1 Pro -> Xuất `vfam-admin-ios-1.5.3.ipa` & `manifest.plist`.
4. Tạo mã QR và phát hành GitHub Releases: `child-android-v1.5.3`, `admin-android-v1.5.3`, `admin-ios-v1.5.3` và Unified `v1.5.3` (Latest).
5. Bắn thông báo giám sát và mã QR lên Telegram kênh HUB-LOG.
