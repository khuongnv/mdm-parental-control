## 2. Chi Tiết Các Bước Thực Hiện (Execution Steps)
- **Bước 1**: Đồng bộ và tăng số hiệu phiên bản:
  - `target-node/app/build.gradle.kts`: `versionCode = 16`, `versionName = "1.5.5"`.
  - `admin-node/pubspec.yaml`: `version: 1.5.5+14`.
  - `admin-node/lib/services/github_release_updater.dart`: `appVersion = 1.5.5`.
  - `admin-node/ios/Runner/AppDelegate.swift`: `CFBundleShortVersionString = 1.5.5`, `CFBundleVersion = 14`.
- **Bước 2**: Biên dịch Child DO Agent (`target-node`):
  - Chạy `gradlew.bat assembleDebug`.
  - Xuất file APK `release/vfam-child-android-1.5.5.apk`.
  - Gắn tag `child-android-v1.5.5` và tạo GitHub Release.
  - Tạo QR Code tải trực tiếp và gửi thông báo Telegram HUB-LOG.
- **Bước 3**: Biên dịch Parent Admin Android (`admin-node`):
  - Chạy `flutter build apk --release`.
  - Xuất file APK `release/vfam-admin-android-1.5.5.apk`.
  - Gắn tag `admin-android-v1.5.5` và tạo GitHub Release.
  - Tạo QR Code và gửi thông báo Telegram HUB-LOG.
- **Bước 4**: Biên dịch và ký số Parent Admin iOS Enterprise từ xa qua Mac M1 Pro:
  - Đồng bộ mã nguồn nén `admin_src.tar.gz` qua SSH.
  - Cài đặt / mở khóa Keychain và nạp chứng chỉ VNPT Enterprise (`VNPT_Enterprise.p12`) + Provisioning Profile (`Prov_HNI_comdhtthniquanlytaptrung.mobileprovision`).
  - Chạy `pod install` và `xcodebuild -exportArchive` xuất `vfam-admin-ios-1.5.5.ipa`.
  - Kéo file IPA về Windows, sinh tệp Apple OTA `manifest.plist`.
  - Gắn tag `admin-ios-v1.5.5` và tạo GitHub Release.
  - Tạo QR Code link `itms-services://` cài trực tiếp cho iPhone/iPad và gửi thông báo Telegram HUB-LOG.
- **Bước 5**: Phát hành Unified GitHub Release `v1.5.5` (`--latest`):
  - Gắn tag `v1.5.5`, push lên remote repository.
  - Đính kèm toàn bộ 4 assets (`vfam-child-android-1.5.5.apk`, `vfam-admin-android-1.5.5.apk`, `vfam-admin-ios-1.5.5.ipa`, `manifest.plist`).
  - Đánh dấu là bản phát hành mới nhất (`--latest`).
